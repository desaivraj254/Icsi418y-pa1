# Vraj's Task List

## Author

Vraj Desai

## Application Name

Vraj's Task List

## Description

Vraj's Task List is a simple webpage for keeping track of tasks.

The user can add a task and choose a Low, Medium, or High priority. Tasks can also be marked as completed, changed back to incomplete, or deleted.

The page also shows the total number of tasks and how many have been completed.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter a task name.
5. Choose a priority.
6. Click **Add Task**.

## Known Problems

There are currently no known problems.

The tasks are not permanently saved. Refreshing or closing the page will clear the task list.
